## 0. 핵심 아트 스타일

- **시각 특징**: 강렬한 검은색 먹선 아웃라인(Ink Outline) + 단순·명확한 셀 셰이딩(Cel-shading)
- **색상 팔레트**: 보더랜드풍의 거칠고 투박한 베이스 + **얼음 원소 강조용 네온 블루/차가운 원색** 포인트 컬러
- **이펙트 기조**: 무거운 3D 파티클 대신 **손그림 2D 텍스처를 팝(Pop)하게 터뜨리는 방식**
  → 시각적 뽕맛 + 후반 최적화 동시 달성 (★ 원작 후반 렉 문제의 정면 해결책)

### 색 역할 규칙 (가독성)
| 색 | 의미 |
|---|---|
| 네온 블루 | 내 얼음/아군 효과 |
| 네온 레드 | 위험 — 약점 마커, 안전구역 경고 장판 |
| 노랑 | 골드/경험치, 헤드어택 (⚠ 아래 리스크 1 참고) |
| 주황/빨강 | 백어택 크리티컬 |

## 2. 플레이어 조작계 (Controller UI)
**캐릭터 아바타가 없는 게임** — 플레이어 움직임 시각화의 핵심 레이어.

| 에셋 | 설명 | 우선순위 |
|---|---|---|
| 네온 마우스 커서 | 외곽선 뚜렷 + 중심 네온 맥동 고유 스프라이트. **커서가 주인공** | **MVP** |
| 공격 범위 가이드라인(데칼) | 커서 따라 지면 투영되는 크고 반투명한 원형 범위 | **MVP** |
| └ 얼음 각성 시 | 테두리에 카툰 고드름 문양 + 서리 오라 일렁임 | **MVP** |
| 기믹 상태 커서 배리언트 | 보스 패턴(채널링/순서 클릭) 진입 시 조준점(Crosshair) 형태로 변형 | **MVP** |

> ⚠ **기술 작업 필요**: OS 하드웨어 커서를 숨기고 스프라이트로 렌더 (아트 아닌 코드 작업). 0.4 후속으로 잡을 것.

## 3. 캐릭터 및 크리처 (Monsters & Boss)
두꺼운 외곽선 + 과장된 애니메이션으로 팝한 느낌.

### 일반 몬스터
| 종족 | 설명 | 우선순위 |
|---|---|---|
| 고블린 | 기본 고블린 전사 (이동/피격/사망) | **MVP** |
| 야만 용사(바바리안) | 거대 무기 인간형 전사 (이동/피격/사망) | 폴리시 |
| 거대 몬스터 배리언트 | 1.5배 크기 + 노란 골드/경험치 아우라 셰이더 | **MVP** (고블린 기준) |

### 레이드 보스 — MVP 타겟
- **해골 마법사 (Skeleton Mage)**: 찢어진 로브의 거대 언데드 마법사
- 필수 애니메이션: 등장 / Idle / 주문 캐스팅(채널링) / 피격 / **기믹 실패 시 그로기** / 산산조각 사망

## 4. 시각 효과 (VFX)
모두 **2D 텍스처 팝** 방식.

### 타격/판정
| VFX | 설명 |
|---|---|
| 기본 검격 슬래시 | 원형 범위 안 사방으로 촤르륵 터지는 흰색/하늘색 카툰 선 궤적 |
| 헤드어택 | 정면 타격 시 노란 스파크 |
| 백어택 크리티컬 | 후면 타격 시 거대한 주황/붉은 불꽃 스파크 |

### 얼음 각성
| VFX | 설명 |
|---|---|
| 얼음 파편 | 데포르메된 투박한 고드름 발사체 3D 메시 |
| 냉기 부여 오버레이 | 적 표면에 스케치풍 서리 문양 + 파랗게 질리는 셰이더 |
| 얼음 폭발 | 냉기 적 피격 시 카툰 링 형태 서리 폭발 |

### 보스 기믹 연출 (→ 보스기믹_기술설계.md와 매핑)
| VFX | 설명 |
|---|---|
| 보스 무적 막 (DamageGate) | 불투명·단단한 육각형 카툰 에너지 배리어 |
| 약점 노출 마커 | 보스 몸에 붙는 네온 레드 글리치 타겟 룬 |
| 안전 구역 예고 장판 | 경고선+빗금 텍스처의 빨간 카툰 데칼 |
| 채널링 방해 구슬 | 마법사 머리 위 흑보라색 소용돌이 마법 구체 |

## 리스크 & 메모 (생성 전 확인)

1. **노란색 중복** — 거대 몹 골드 아우라(상시) vs 헤드어택 스파크(순간)가 둘 다 노랑.
   거대 몹 타격 시 헤드 스파크가 묻힐 수 있음 → **헤드어택은 더 밝은 흰노랑/채도 차이**로 구분.
2. **룩 통일** — AI 생성 2D 일러스트 ↔ 3D 셀셰이딩 메시의 톤 일치가 관건.
   2D 스프라이트 위주로 가면 통일성·최적화 모두 유리.
3. **네온 커서 = 코드 작업 포함** — 하드웨어 커서 숨김 + 스프라이트 렌더. 아트만으로 안 됨.
