# Re:Blade 역기획 문서

> 참고 게임: Re:Blade (STAGE Games, 2026.05.18 출시)  
> 목적: 클론 베이스 개발 + 차별점 설계  
> 작성일: 2026-06-01

---

## 1. 게임 루프 구조

```
[전투] → [업그레이드 선택] → [전투] → ... → [레이드(보스)] → [깨달음 획득]
              ↑ 각성 레벨업 시 각성 카드 선택도 병행
```

- **전투**: 타이머 카운트다운, 0이 되면 종료
- **업그레이드**: 전투 후 골드로 구매 (시장 몬스터 수, 데미지, 공속, 범위 등)
- **레이드**: 스테이지별 보스전, 처치 시 깨달음 포인트 획득
- **연대기**: 몬스터 처치 수 누적 → 일정 수 달성 시 달성 보상

---

## 2. 전투 시스템

| 요소 | 내용 |
|---|---|
| 조작 | 마우스 커서를 따라 원형 범위 이동 |
| 오토어택 | 범위 내 몬스터 자동 공격, 초당 약 2.22대 (후반 기준) |
| 헤드어택 | 적 정면 공격 시 피해량 20% 증가 |
| 백어택 | 적 후면 공격 시 치명타 적중률 증가 |
| 범위 수치 | 초기 2, 성장하면서 최대 15+ |

**보스 패턴 (원작 확인):**
- 무적 구간 존재
- 바람 패턴: 마우스를 강제로 밀어냄
- 힐 패턴: 체력 회복하는 보스 존재
- 처형 스킬은 보스에게 적용 안 됨

## 3. 각성 시스템 (런마다 초기화)

- 업그레이드 구매 → 각성 레벨 누적 → 레벨업 시 3개 카드 중 1개 선택
- **원소 계열**: 얼음 / 불 / 번개
- **히든 각성**: 특정 각성 조합 조건 달성 시 해금

### 얼음 각성 트리

| 단계 | 각성명 | 효과 |
|---|---|---|
| 기본 | 얼음파편 | 공격 적중 시 20% 확률로 얼음파편 발사 |
| 2티어 | 냉기 부여 | 얼음파편 적중 시 냉기 상태 부여 |
| 2티어 | 얼음폭발 | 냉기 상태 적 피격 시 40% 확률 얼음폭발 |
| 2티어 | 관통 | 얼음파편이 적 관통 |
| 3티어 | 파편 분열 | 얼음파편 적중 시 추가 파편 생성 |
| 3티어 | 추가 발사 | 공격 적중 시 60~100% 확률로 추가 얼음파편 |
| 히든 | 얼음파편 프로페자 | 공격+치명타 시 얼음파편 3개 동시 발사 |

### 범용 각성

- 세 번째 공격 시 피해 30%→60%→90%→120% 증가
- 처형: 체력 X% 미만 즉시 처치 (보스 제외)
- 선재공격: 체력 100% 적 공격 시 무조건 치명타
- 히든 "숨끊기": 공격 후 30% 미만 즉시 처치 + 공격 시 데미지 100% 증가

---

## 4. 깨달음 시스템 (영구 성장)

- **4개 카테고리**: 공격 / 속도 / 범위 / 치명
- **트레이드오프 구조**: 각 노드에 디버프 동반
  - 예: "공격력 20% 증가, 공속 감소"
  - 예: "치명타율 증가, 공격력 감소"
- 포인트 환불 가능 (페널티 없음)
- 후반부 노드는 100만~200만+ 골드 필요

---

## 5. 유물 시스템

- 특정 종족 몬스터 처치 시 낮은 확률로 유물 상자 드롭
- 상자 오픈 시 해당 종족 유물 5종 중 랜덤 1개 획득
- 단독 효과 없음, 2종 이상 세트 조합 시 세트 효과 발동
- 유물 드롭 확률 업그레이드로 증가 가능 (최대 100% 노드)

---

## 6. 연대기 시스템

- 몬스터 처치 수 누적 기록
- 일정 수 달성 시 달성 보상 (자원 교환 보너스 등)
- 같은 몬스터 많이 처치할수록 단계 해금 → 자완별 보너스 효과

---

## 7. 무기 & 회차 시스템

- 검마다 고유 기본 스탯 (데미지 범위, 공속, 치명타율, 공격 범위)
- 시작 각성 레벨 존재 (예: 5레벨 시작 검)
- 검 종류 다수 (기사의 검, 기사의 단검, 야만 용사의 단검 등)
- 20스테이지 보스 처치 시 검 엔딩 + 새 검 해금

---

## 8. 업그레이드 (골드 상점)

| 항목 | 설명 |
|---|---|
| 시장 몬스터 수 | 전투 시작 시 몬스터 수 증가 |
| 데미지 / 공속 / 범위 / 치명 | 기본 스탯 상승 |
| 전투 시간 | 한 판 지속 시간 증가 |
| 처치 보상 배수 | 5배 → 50배 노드 |
| 경험치 획득량 | 각성 레벨업 속도 증가 |
| 리스폰 확률 | 처치 시 몬스터 재소환 확률 |
| 거대화 확률 | 거대 몬스터 보상 150% |
| 타워 | 공격력의 10% 데미지 자동 포탑 |
| 나무 | 매초 성장, 전투 종료 시 성장량 비례 보상 |

## 9. 보스 기믹 시스템 ⭐ (차별화)

원작 Re:Blade의 보스는 단순 스탯 벽 + 무적 구간 구조.  
이 게임은 **로스트아크식 기믹**을 보스에 적용해 "스탯이 아닌 패턴 이해"로 클리어하는 구조를 추가한다.

일반 전투는 기존 빠른 리듬 유지, 보스전만 기믹 적용.

```
일반 전투 (10~30초)  →  파밍 / 성장
보스전 (레이드)       →  기믹 + 집중 전투, 클리어가 관문
```

### 기믹 설계 원칙

1. **커서 조작으로 해결**: 키보드 입력 없이 마우스 위치/이동으로만 기믹 수행
2. **실패 패널티**: 기믹 실패 시 보스 체력 회복 or 무적 구간 발동 (즉사 아님)
3. **시각적 명확성**: 기믹 발동 전 예고 연출 → 플레이어가 읽을 수 있어야 함
4. **보스마다 고유 기믹 1~2개**: 기믹 과부하 방지

### 기믹 유형 목록

| 기믹명 | 방식 | 실패 패널티 |
|---|---|---|
| **약점 노출** | 보스 특정 부위에 커서 올려야 딜 들어감 | 딜 0 (부위 이외 무적) |
| **안전 구역** | 장판 발동, 커서를 특정 영역 밖으로 빼야 함 | 공격력 X초 감소 |
| **채널링 방해** | 보스 힐/강화 채널링 중 특정 포인트에 커서 유지 | 보스 체력 회복 or 버프 적용 |
| **순서 클릭** | 보스 몸의 문양을 순서대로 클릭 | 보스 전체 체력 일부 회복 |
| **유도** | 보스를 특정 함정 위치로 유인 (커서로 어그로 조작) | 보스 강화 상태 전환 |
| **바람 저항** | 외부 힘이 커서를 밀 때 정해진 위치 유지 | 일정 피해 + 커서 강제 이동 |

### 보스 기믹 예시 설계

#### 보스 A — 고블린 대족장
- **페이즈 1**: 일반 딜
- **기믹**: 방패 올리면 전면 무적 → 커서를 후면으로 이동해서 백어택 포지션 유지
- **페이즈 2 (체력 50%)**: 돌진 예고 → 안전 구역(원 표시)으로 커서 이동

#### 보스 B — 해골 마법사
- **기믹 1**: 힐 채널링 발동 → 채널링 포인트(보스 머리 위 구슬)에 커서 X초 유지해서 방해
- **기믹 2**: 순서 클릭 — 보스 주변 4개 룬을 순서대로 클릭 (순서 틀리면 리셋)

#### 보스 C — 그리핀 (원작에도 등장)
- **기믹**: 바람 패턴 — 커서를 바람 반대 방향으로 보정하며 특정 포인트 유지
- **기믹 2**: 공중 강하 예고 → 그림자 위치에서 커서 빼기

### 구현 우선순위

| 우선순위 | 기믹 유형 | 이유 |
|---|---|---|
| 1 | 약점 노출 | 구현 단순, 커서 이동만으로 해결 |
| 2 | 안전 구역 | 시각적으로 명확, 직관적 |
| 3 | 채널링 방해 | 긴장감 높음, 타이밍 요소 |
| 4 | 순서 클릭 | 퍼즐 요소, 후반 보스용 |
| 5 | 유도 | 구현 복잡도 높음, 추후 추가 |

## 10. 차별화 포인트 요약

| 원작 문제 | 이 게임의 개선 방향 |
|---|---|
| 보스 = 스탯 벽 + 무적 구간 | 보스마다 고유 기믹으로 "읽는 재미" 추가 |
| 번개/불 원소 미구현 | 완전한 3원소 트리 구현 |
| 각성 원소 고정 (한 번 선택 후 전환 불가) | 멀티 원소 시너지 허용 검토 |
| 후반 렉 (몬스터/이펙트 폭증) | 이펙트 풀링, 파티클 제한 |
| 재화 획득 경로 불명확 | UI에 획득 경로 명시 |
