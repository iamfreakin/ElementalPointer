# ElementalPointer — 기획서 초안

> 참고작: Re:Blade (STAGE Games) / 클론 베이스 + 차별점  
> 목표: 얼리액세스 출시  
> 엔진: UE 5.8 (C++ 코어 + BP·DataAsset)  
> 작성일: 2026-06-01

---

## 1. 한 줄 컨셉

> 마우스 커서로 검의 공격 범위를 조종하는 인크리멘탈 액션 로그라이크.  
> **차별점: 보스전에 로스트아크식 기믹을 도입해 "스탯 벽"이 아닌 "패턴 이해"로 클리어한다.**

---

## 2. 핵심 재미 (Core Pillars)

| 기둥 | 설명 |
|---|---|
| 짧고 강한 루프 | 한 판 10~30초, "한 판만 더"를 부르는 호흡 |
| 커서 포지셔닝 | 키 연타 없이 마우스 위치·타이밍으로 전투 통제 |
| 성장의 뽕맛 | 각성으로 빌드가 굴러가고, 깨달음으로 영구히 세짐 |
| 기믹 보스 (차별점) | 일반 전투는 빠르게, 보스는 읽고 대응하는 관문 |

---

## 3. MVP 범위 정의

### 포함 (반드시)
- 커서 기반 오토어택 전투 (범위 내 적 자동 공격, **캐릭터 없이 커서=공격범위**)
- 적 스폰 + 전투 타이머 (한 판 성립)
- 전투 후 골드 업그레이드 상점
- **각성** — 레벨업 시 3선택 1 카드, 런마다 초기화
- **깨달음** — 보스 처치 포인트로 영구 스탯업, 환불 가능
- **유물 세트** — 종족 드롭 + 2종 이상 세트 효과
- 기믹 보스 1종 (차별점 검증용)

### 제외 (MVP 이후)
- 연대기(처치 누적) — 메타 레이어, 나중에 얹음
- 다중 무기/회차 — 검 1자루로 시작
- 3원소 풀 트리 — 얼음 1계열만 먼저
- 히든 각성 조합

### MVP 성공 기준
> "전투 → 각성/업그레이드 → 더 강해진 채로 다음 전투 → 보스 기믹 클리어 → 깨달음으로 영구 성장"  
> 이 1사이클이 **'한 판만 더' 욕구를 만드는가**를 플레이로 검증.

---

## 4. 시스템 우선순위 (의존성 순)

```
커서 입력  →  오토어택/데미지  →  적 스폰/타이머  →  전투 종료/보상
                                                          ↓
                              각성(판내) ─┐
                              업그레이드  ─┼→  성장 1사이클
                              깨달음(영구)─┘
                                                          ↓
                              유물 세트  →  기믹 보스 (차별점)
```

> 보스 기믹은 코어 전투(딜·커서)가 돌아간 뒤에야 얹힌다.  
> 단, 커서 투영 작업은 기믹 M1과 동일 → 헛수고 없음.

## 5. 시스템 요약 (MVP 기준)

### 5.1 전투
- **플레이어 = 커서 = 원형 공격 범위.** 걸어다니는 캐릭터/아바타 없음.
  마우스 커서를 따라 공격 범위 원이 이동하며, 범위 내 적을 오토어택.
- **무대(arena) 구조**: 넓은 월드가 아니라 **화면 한 장짜리 고정 무대.**
  카메라 고정(스크롤 없음), 커서는 화면 안에서만 움직임.
- **시점**: 쿼터뷰(45도). 화면 커서 → 전투 평면(Z=0) deproject 투영으로
  커서가 가리키는 평면 지점에 공격 범위 원이 찍힘.
- 헤드어택(정면 +20% 피해) / 백어택(후면 치명 확률↑)
- 전투 타이머 0 → 종료

#### 전투 무대(L_Combat) 셋업 — 확정값 (Phase 0.2)
- **레벨**: `/Game/Maps/L_Combat`
- **바닥(arena)**: 2000×2000 (Floor scale 2), 중심 원점
- **카메라**: Perspective, **FOV 40**, Location `(-3000, -3000, 3600)`, Rotation `pitch -42 / yaw 45 / roll 0`
  - 낮은 FOV 망원으로 왜곡 최소화 + 약간의 거리감 유지 (정통 아이소 ortho는 거리감이 0이라 기각)
  - `Auto Activate for Player = Player 0` (C++ 없이 플레이 시 자동 뷰)
- TODO(아트): 바닥을 레퍼런스처럼 "두꺼운 블록 + 공중 섬", 떠다니는 구름/돌 배경

### 5.2 각성 (런 내 성장, 초기화)
- 경험치 → 각성 레벨업 → 3장 중 1장 선택
- 얼음 계열 트리 (파편 → 냉기 → 폭발 → 분열)
- 범용 카드 (3타 강화, 처형, 선재공격 등)

### 5.3 깨달음 (영구 성장)
- 보스 처치 시 포인트 획득
- 4 카테고리(공격/속도/범위/치명), 노드마다 트레이드오프
- 환불 무료 → 빌드 실험 자유

### 5.4 유물 세트
- 종족 처치 시 낮은 확률 상자 드롭
- 종족별 5종 중 랜덤 1
- 2종 이상 보유 시 세트 효과 발동

### 5.5 기믹 보스 (차별점)
- 페이즈 상태머신 + 기믹(약점/안전구역/채널링/순서)
- 딜 게이트로 "딜 가능/무적" 관리
- 상세 → `보스기믹_기술설계.md`

## 6. 차별화 요약

| 원작 한계 | 이 게임 |
|---|---|
| 보스 = 스탯 벽 + 무적 구간 | 보스마다 고유 기믹, 읽는 재미 |
| 재화 획득 경로 불명확 | UI에 획득 경로 명시 |
| 후반 렉 (이펙트 폭증) | 이펙트 풀링/파티클 제한 설계 |
| 각성이 단순 수치 증가 | 메커니즘 변화형 카드 비중↑ |
